Lưu ý CORS cho MinIO local

MinIO cần cho phép PUT từ origin của trang test. Chạy lệnh sau nếu upload bị lỗi CORS: 

mc alias set local http://localhost:9000 <user> <pass>
mc admin config set local api cors_allow_origin="*"
mc admin service restart local
